# MTS Progressive Mathematics Curriculum Backbone

Canonical concept-first progression layer for Grades 1–12.

## Layering

NC standards cache → validates/enriches this backbone → CCS yearly pacing selects active concepts → Worksheet Spec.

The canonical file is `progressive-math-backbone.json`. It intentionally omits standards in high-level v1 and is not official CCS pacing.

## Unit families
1. Number Sense & Operations
2. Fractions, Ratios & Proportional Reasoning
3. Patterns, Algebra & Functions
4. Geometry, Measurement & Trigonometry
5. Data, Statistics & Probability
6. Advanced Modeling / Connections
