# Generate Weekly Worksheets

1. Capture original human intent and run overrides.
2. Load shared and subject configuration.
3. Resolve grade, week, curriculum, sources, and confidence.
4. Create one canonical Worksheet Spec.
5. Apply the subject verifier and independent reasoning review.
6. Reconcile worksheet and key from the same spec.
7. Copy the applicable master template and render.
8. Perform targeted content QA and visual layout QA.
9. Enforce enabled gates.
10. Publish approved artifacts and persist the run manifest.
