# Program Guidance

## Objective

Develop MTS AI Generation as a stable, efficient, reviewable system for recurring educational content.

## Strategy

- Consolidate shared worksheet infrastructure once.
- Preserve Math and ELA as distinct subject modules.
- Improve through measured runs, defects, user feedback, and regression tests.
- Promote repeated successful practices into shared skills only when their reuse is proven.
- Keep authoritative curriculum provenance and confidence visible.
- Record planned improvements in `docs/plans/` and architectural decisions in
  `docs/architecture-decisions/`.
