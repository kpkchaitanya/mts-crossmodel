# Execution Plans

Use an execution plan for migrations, architecture changes, large refactors, or work spanning multiple
verification stages.

Each plan must include:

1. Original human intent
2. Scope and exclusions
3. Current state and evidence
4. Target state
5. Phased implementation steps
6. Validation and rollback approach
7. Decisions and unresolved risks
8. Progress status

Plans are living documents. Update status and decisions as work proceeds.
